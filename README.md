## 二、怎么用？（三种方式）

### 方式 A：直接下载打开（最简单）

1. 打开仓库：https://github.com/yangbo4100064/solar-system-orbits  
2. 点击绿色 **Code** → **Download ZIP**  
3. 解压到任意文件夹  
4. **双击 `index.html`**，用 Chrome / Edge / Firefox 打开  

> 需要能访问互联网（页面从 CDN 加载 three.js）。若公司网络屏蔽 CDN，见下方「离线注意」。

### 方式 B：用 Git 克隆

```bash
git clone https://github.com/yangbo4100064/solar-system-orbits.git
cd solar-system-orbits
```

然后双击 `index.html`，或：

```bash
npx --yes serve .
```

终端里会给出本地地址（如 `http://localhost:3000`），用浏览器打开即可。

### 方式 C：在线预览（可选）

GitHub 本身**不会**自动运行 3D 页面。若要用网页直链预览，可：

1. 仓库 **Settings → Pages**，Source 选 `main` 分支根目录，保存  
2. 几分钟后访问：  
   `https://yangbo4100064.github.io/solar-system-orbits/`  

（若未开启 Pages，则只用方式 A/B。）

## 三、界面操作说明

### 鼠标 / 触控

| 操作 | 作用 |
|------|------|
| **左键拖拽** | 旋转视角 |
| **滚轮** | 缩放 |
| **右键拖拽** | 平移 |
| **点击天体** | 底部显示参数（半径、体积、轨道、季节等） |

### 左上角控制面板

| 控件 | 作用 |
|------|------|
| **速度** | 仿真时间快慢（公转/彗星推进） |
| **轨道线** | 显示/隐藏轨道 |
| **标签** | 显示/隐藏名称 |
| **彗星** | 显示/隐藏哈雷、海尔–波普 |
| **行星放大** | 只放大行星球体（太阳与轨道仍按 AU） |
| **行星也相对 AU 真实尺度** | 勾选后行星极小（物理尺度） |
| **焦点** | 镜头跟随：太阳系 / 地球四季 / 各行星系 / 彗星 |
| **重置视角** | 回到默认相机 |
| **彗星→近日点** | 跳到彗星近日点，便于看彗尾 |
| **地球四季模式** | 地轴、赤道、节气、晨昏线 |
| **跳转节气** | 依次：春分 → 夏至 → 秋分 → 冬至 |
| **自转速度** | 地球自转快慢 |

### 右上角（四季模式开启时）

实时显示：

- 北半球当前季节（春/夏/秋/冬）  
- 日序、日心距 \(r\)、太阳赤纬 \(\delta\)  
- 四季进度条  

### 底部信息栏

点击太阳、行星、卫星、彗星后，显示详细数据与简要科普说明。

## 四、功能一览

1. **八大行星**  
   - 开普勒轨道（半长轴、偏心率、倾角、周期）  
   - 体积按 IAU 平均半径 \(V=\frac{4}{3}\pi R^3\) 比例  

2. **太阳**  
   - 半径始终为真实 \(R_\odot/\mathrm{AU}\)（约 0.00465 AU）  
   - 内行星轨道不会穿进太阳  

3. **主要卫星**  
   - 月球、火卫、伽利略卫星、土卫、天卫、海卫等  

4. **彗星**  
   - 1P/哈雷、C/1995 O1 海尔–波普  
   - 核等效半径与体积  
   - 离子尾（Type I）+ 尘埃尾（Type II，多 β）  
   - 活动度随日心距变化  

5. **地球自转与四季**  
   - 黄赤交角 **23.44°**  
   - 自转 + 公转  
   - 春分 / 夏至 / 秋分 / 冬至标记  
   - 说明：四季主因是地轴倾斜，不是日地远近（近日点在 1 月初）  

更细的轨道数值见：**[orbital-elements.md](./orbital-elements.md)**。

## 五、推荐体验路径（给第一次用的人）

1. 打开 `index.html`  
2. 焦点选 **「地球 · 公转与四季」**，勾选 **「地球四季模式」**  
3. 点几次 **「跳转节气」**，观察地轴相对太阳的方向变化  
4. 焦点改 **「哈雷彗星」**，点 **「彗星→近日点」**，看双彗尾  
5. 焦点 **「木星系」**，查看伽利略卫星轨道  
6. 点击任意天体，阅读底部参数

## 六、常见问题

**Q：打开是白屏 / 黑屏？**  
- 需联网加载 three.js（unpkg CDN）  
- 换 Chrome/Edge 再试  
- 不要用过旧的 IE  

**Q：行星太小看不见？**  
- 取消勾选「行星也相对 AU 真实尺度」  
- 调大「行星放大」滑条  
- 地球在四季模式下有额外显示下限，更容易看见  

**Q：太阳太大、金星轨道进太阳？**  
- 当前版本太阳按 AU 真值；请确认用的是本仓库最新 `index.html`  

**Q：四季和真实日历完全一致吗？**  
- 节气日序为常用近似（非历书精密推算）  
- 倾角、成因与定性变化正确  

**Q：能当精确星历用吗？**  
- 不能。这是教学/可视化演示，不是 JPL Horizons 级精密星历。

## 七、技术说明（简）

- 单文件前端：`index.html` + ES Module + Three.js r160  
- 二体开普勒：\(M=E-e\sin E\)，再转真近点角与三维位置  
- 场景：1 AU → 固定场景尺度；太阳半径 \(=\ R_\odot/\mathrm{AU}\) 同比例
