# 太阳系卫星与轨道可视化

基于 **NASA / JPL / IAU** 常用参数的交互式 3D 太阳系演示（Three.js）。

## 功能

- 八大行星真实开普勒轨道与体积比例（平均半径）
- 主要天然卫星轨道
- 太阳半径相对 AU 的物理真值（内行星轨道不穿日）
- 哈雷彗星 (1P/Halley)、海尔–波普 (C/1995 O1)：核体积 + Type I/II 彗尾
- **地球公转与四季**：黄赤交角 23.44°、自转、春分/夏至/秋分/冬至

## 使用

用浏览器直接打开 `index.html`（需联网加载 three.js CDN）：

```text
index.html
```

或本地静态服务：

```bash
npx --yes serve .
```

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 完整 3D 可视化（自包含） |
| `orbital-elements.md` | 主要卫星轨道根数表 |

## 操作

- 拖拽旋转 / 滚轮缩放 / 右键平移
- 焦点选「地球 · 公转与四季」，勾选「地球四季模式」
- 「跳转节气」依次查看春分、夏至、秋分、冬至
- 点击天体查看参数

## 许可

演示用途；天文参数来自公开的 IAU / NASA / JPL 常用值。
